Importação e Envio de NFSe Barueri

Manual de instruções para integração Protheus

Fluxo do Processo:
  1. Entre no Portal da Prefeitura de Barueri e selecione a opção exportar NFSe.
  2. O Arquivo ZIP chegará no e-mail informado.
  3. Salve o arquivo em uma pasta local do seu PC.
  4. Acesse a rotina no menu Integração - NFSe Barueri.
  5. O Protheus vai abrir uma tela perguntando se deseja importar o Arquivo ZIP para atualização das NFSe mais recentes que estão na Prefeitura.
  6. Selecione SIM se precisar atualizar, ou NÃO se já estiver atualizado.
  7. Se escolher a opção SIM, aparecerá uma mensagem para aguardar o processamento. Dependendo da quantidade de NFSe contidas no Arquivo ZIP, pode levar até 2 minutos. Porém, o sistema permitirá que a tela seja acessada e efetuará os envios das NFSe já processadas pela rotina.
  8. Clique na opção do menu NFSe Emitidas.
  9. Aparecerá a lista de todas as NFSe importadas da Prefeitura, ordenada por data de importação.
  10. O botão Atualizar serve para a rotina puxar novas NFSe que estão sendo processadas em segundo plano.
  11. Com o botão Filtro, é possível filtrar um lote por data específica.
  12. A primeira coluna da tela da lista das NFSe (ENVIAR) é a responsável pelo envio das NFSe e dos XMLs referentes àquele lote do cliente selecionado.
  13. O usuário logado irá receber uma cópia do e-mail enviado para o cliente.
